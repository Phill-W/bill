# 报销单数据库表结构定义

## 1. 表结构总览

| 序号 | 表名 | 中文名称 | 说明 |
| --- | --- | --- | --- |
| 1 | fk_reim_main | 报销单主表 | 存储报销单主信息、报销人、部门、公司、业务类型和金额汇总 |
| 2 | fk_reim_itinerary | 补录行程表 | 存储报销单补录行程明细 |
| 3 | fk_reim_subsidy | 补助信息表 | 存储按行程生成的补助信息和补助金额 |
| 4 | fk_subsidy_calendar | 补助日历表 | 存储每一天的餐费、交通、通讯补助勾选和金额 |
| 5 | fk_reim_allocation | 费用归属及分摊表 | 存储补助金额在费用归属公司和项目上的分摊结果 |

## 7. 表关系说明

| 主表 | 从表 | 关联字段 | 关系说明 |
| --- | --- | --- | --- |
| fk_reim_main | fk_reim_itinerary | fk_reim_itinerary.main_id = fk_reim_main.id | 一张报销单包含多条补录行程 |
| fk_reim_main | fk_reim_subsidy | fk_reim_subsidy.main_id = fk_reim_main.id | 一张报销单包含多条补助信息 |
| fk_reim_itinerary | fk_reim_subsidy | fk_reim_subsidy.itinerary_id = fk_reim_itinerary.id | 一条行程对应一条补助信息 |
| fk_reim_main | fk_subsidy_calendar | fk_subsidy_calendar.main_id = fk_reim_main.id | 一张报销单包含多条补助日历 |
| fk_reim_itinerary | fk_subsidy_calendar | fk_subsidy_calendar.itinerary_id = fk_reim_itinerary.id | 一条行程对应多条补助日历 |
| fk_reim_subsidy | fk_subsidy_calendar | fk_subsidy_calendar.subsidy_id = fk_reim_subsidy.id | 一条补助信息对应多条补助日历 |
| fk_reim_main | fk_reim_allocation | fk_reim_allocation.main_id = fk_reim_main.id | 一张报销单包含多条费用分摊 |

## 8. 公共字段约定

| 字段 | 说明 |
| --- | --- |
| id | 业务主键，当前代码中使用 32 位字符串 |
| main_id | 报销单主表 ID |
| sort_no | 页面展示和明细保存排序号 |
| creation_time | 创建时间 |
| update_time | 更新时间 |
| is_deleted | 逻辑删除标识：0 否，1 是 |
| 金额字段 | 使用 `DECIMAL(18,2)`，保留 2 位小数 |
| 比例字段 | `allocation_ratio` 使用 `DECIMAL(10,6)`，保存 0-1 的小数值 |
